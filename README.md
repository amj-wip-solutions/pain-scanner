# PAINRADAR

Automated pipeline that mines public complaints, classifies and scores them, and delivers a weekly brief of high-signal SaaS opportunities. Day 1 vertical: recruiting and talent acquisition.

## Documentation

- [Setup walkthrough](SETUP.md) — accounts, local install, first run
- [Product brief](docs/product.md) — problem, audience, sources, scoring, brief format, roadmap
- [Technical specification](docs/tech.md) — architecture, data model, pipeline, contracts, deploy

## Stack

TypeScript · Bun · Next.js · Supabase + pgvector · GitHub Actions · Gemini 2.0 Flash · Resend · Vercel.

Recurring cost: 0 EUR / month on free tiers at expected volume.
